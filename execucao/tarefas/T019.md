## Entrega
1. Criar matcher puro de objetivo contra evento de domínio sem introduzir dependência sim → protocol.
2. Filtrar por runId e, quando presente no payload, questId.
3. Suportar objetivos diretos:
   - enter_area → area_entered / areaId
   - interact → interaction_completed / targetId
   - collect → item_collected / itemId
   - defeat → entity_died / encounterId
   - choose → choice_committed / choiceId
4. Diferenciar mismatch de evento, alvo, rota e configuração inválida.
5. Deixar survive, escort e objetivos compostos explicitamente fora do escopo.

## Critérios de aceite
- [ ] EventEnvelope real do protocol é estruturalmente compatível com o matcher.
- [ ] Evento de outro run não progride objetivo.
- [ ] questId explícito incorreto não progride objetivo.
- [ ] Tipo ou alvo incorreto não casa.
- [ ] Cinco objetivos diretos casam nos eventos corretos.
- [ ] Objetivo direto mal configurado retorna invalid_objective.
- [ ] Objetivos não suportados retornam unsupported_objective.
- [ ] packages/sim não importa packages/protocol.
