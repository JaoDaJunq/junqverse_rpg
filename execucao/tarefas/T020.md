## Entrega
1. Aplicar EventEnvelope compatível ao objetivo do estágio ativo usando o matcher da T019.
2. Armazenar eventIds processados em objectiveState para idempotência entre estágios.
3. Acumular count para collect/defeat; default 1.
4. Usar collectedIds para impedir coleta duplicada por collectibleId.
5. Ao satisfazer a meta, chamar a progressão da T018 e preservar dedupe global após a troca de estágio.
6. Manter objetivos temporizados/compostos fora deste ticket.

## Critérios de aceite
- [x] Evento repetido não incrementa objetivo.
- [x] Mesmo collectibleId com eventId novo não incrementa coleta.
- [x] Collect/defeat podem exigir count > 1.
- [x] Evento que conclui objetivo avança o stage e emite actions da T018.
- [x] processedEventIds sobrevivem à troca de estágio.
- [x] Evento de outro run não altera progresso.
- [x] Progresso final continua válido em QuestProgressSchema.
- [x] Event id inválido nunca é persistido.
