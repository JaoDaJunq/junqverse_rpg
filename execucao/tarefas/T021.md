## Entrega
1. Implementar progresso puro para objetivo `survive`.
2. O contrato canônico do objetivo usa `durationTicks` inteiro positivo.
3. Iniciar a contagem no primeiro tick autoritativo processado pelo estágio.
4. Calcular progresso por `currentTick - surviveStartedAtTick`, nunca por número de chamadas.
5. Completar o estágio via runtime da T018 quando a duração for atingida.
6. Preservar `processedEventIds` ao atravessar o estágio survive.
7. Expor elapsedTicks e remainingTicks para futura UI.

## Critérios de aceite
- [ ] Mesmo tick processado duas vezes não adianta tempo.
- [ ] Pause/frames de render não interferem porque só tick de simulação conta.
- [ ] Salto de ticks calcula elapsed corretamente.
- [ ] Estágio conclui exatamente ao atingir durationTicks.
- [ ] completionActions/checkpoint/entryActions seguintes vêm do runtime T018.
- [ ] processedEventIds sobrevivem à transição.
- [ ] Estágio survive terminal conclui a quest.
- [ ] QuestProgress final continua serializável.
- [ ] durationTicks inválido é rejeitado.
- [ ] tick regressivo/inválido é rejeitado.
