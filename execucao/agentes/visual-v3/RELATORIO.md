# RELATÓRIO — decisão Visual V3

## Motivo

O playtest visual do P0 mostrou que o Visual V2 ainda depende demais de linhas e formas de debug apesar de o projeto já possuir assets temporários suficientes.

Também foi identificado que usar o Jão como laboratório de todo experimento mistura duas necessidades diferentes:
- validar o herói oficial;
- experimentar gameplay/VFX sem compromisso.

## Decisão

Criar um segundo personagem jogável chamado **Teste** e um seletor no topo da tela.

O Teste passa a ser a sandbox oficial para novas skills, assets e efeitos.

## Direção visual

Usar mais Pixel Crawler e Brackeys VFX antes de procurar novos packs.

Prioridades:
1. sprites reais;
2. VFX reais;
3. Graphics somente para telegraph técnico;
4. decoração intencional da arena;
5. diferença visual clara entre personagens e arquétipos.

## Problema específico do Passo Relâmpago

O rastro atual é percebido como uma lança/faixa frontal.

A correção deve usar trail e afterimage atrás do personagem, preservando o Q oficial do Jão.

## Resultado esperado

O próximo playtest deve permitir comparar:
- Jão como kit oficial;
- Teste como laboratório visual/gameplay.

A T017 continua REVIEW até o playtest humano final.
