# Como executar usando um modelo mais barato

## Ciclo de trabalho
1. Escolher primeira tarefa TODO cujas dependências sejam DONE.
2. Ler AGENTS.md, 00_CONTEXTO.md, STATUS, HANDOFF, ticket e referências.
3. Pedir uma entrega completa e revisar o resultado real.
4. Confirmar critérios, registrar evidência e só então marcar DONE.
5. Avançar pelo grafo de dependências.

A ordem numérica é guia; dependências são a regra. Não marcar metade como DONE. Comportamento, arquivos alterados, comandos/resultados, o que não foi testado e próxima tarefa devem constar no handoff.
