# JUNQVERSE Ecos do Vale
## Projeto de jogo e pacote de execução por IA
Versão do planejamento 1.0 • 22 de setembro de 2026 • Responsável criativo: MVP

Este repositório contém o planejamento oficial e a implementação incremental do JUNQVERSE. A proposta é um RPG de ação 2D no navegador. O planejamento documental continua sendo a autoridade de produto; código entregue só conta quando há evidência em revisão.

## Começar
1. Leia [00_CONTEXTO](00_CONTEXTO.md) e [AGENTS](AGENTS.md).
2. Consulte [STATUS](execucao/STATUS.md) e [HANDOFF](execucao/HANDOFF.md).
3. Execute uma tarefa por vez a partir de [execucao/tarefas](execucao/tarefas).
4. Use os contratos em [docs](docs) como autoridade.
5. Só avance após verificação e revisão.

A implementação T001 adiciona npm workspaces, Phaser 3.90.0, Vite, TypeScript strict e os comandos reproduzíveis. O restante continua governado pelo pacote de planejamento.
